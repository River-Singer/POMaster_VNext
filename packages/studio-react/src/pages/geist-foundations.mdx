# Foundations：Geist 在 React 画廊里怎么呈现

> 本页说明 Geist 规范页用的组件从哪来、哪些是近似。规则本身在侧栏最上方的「规范」分区，
> 规范源是 `packages/cli/seeds/design-standards/geist.yaml`。

## 选型（项目决策 D-S9）

React 栈的设计体系是 Vercel Geist，组件用 **shadcn/ui + Tailwind CSS 4**，图标用 **lucide-react**。
这是项目的选型决策（D-S9），不是从 Geist 的参照里推出来的；摘要见 `docs/design-standard.md`。

## 为什么不是 Geist 官方组件

1. **官方 Geist 组件包没有公开发布**：`@vercel/geistcn` 与图标包 `@vercel/geistcn-assets` 在 npm 上都查不到
   （2026-11 核实）。公开后再评估替换，规范源里的 `ICON.LIBRARY` 已登记这个待替换项。
2. **官方 `geist` npm 包只分发字体**，且字体加载器依赖 Next.js；本画廊改从 Google Fonts 加载
   Geist 与 Geist Mono（字重 400–600），见 `.storybook/preview-head.html`。
3. **社区 `@geist-ui/core` 已归档**，与现行 Geist 不同代，不用。

## 哪些是近似

| 方面 | 本画廊的做法 | 与官方的关系 |
| --- | --- | --- |
| 颜色 | shadcn/ui neutral 主题的成对变量（`src/styles/geist.css`） | 近似：拿到 Geist 官方色板后替换 |
| 排版 | `text-heading-*` / `text-button-*` / `text-label-*` / `text-copy-*` | 类名与字号取自 Geist 官方排版页；行高、字重、字距官方未公开，是规范里的项目决策位 |
| 圆角 | 小件 6px、卡片 12px、浮层按材质分档 | 取自 Geist 官方材质页 |
| 栅格 | 12 / 6 / 4 列 | 取自 Geist 官方栅格页 |
| 间距 | Tailwind 4 的 0.25rem 阶梯 | Geist 没有公开间距 foundation，用 Tailwind 阶梯 |
| 组件 | shadcn/ui 源码（`src/components/ui/`） | 外观按上面的主题变量走，不是 Geist 官方组件 |

## 与 antd 页同处一个 Storybook

本实例同时渲染 antd 组件页（与 Vue 画廊对照浏览）。Tailwind 不加全局 preflight，只在 `.geist-root`
里生效；antd 的 reset.css 放进最低的 CSS 层，免得它的元素选择器压过 Tailwind 工具类。两边互不影响，
层序见 `.storybook/preview.css`。

## 引用纪律

- 本页和 Vue 画廊的「Foundations/Geist（官方站参照）」页一样，只说明来源，不是规范文本；规则以规范分区为准。
