## Entity

- 起步值:UNKNOWN
- 填写指引:实体清单逐条登记:实体名 + 一句话定义。

## Table

- 起步值:UNKNOWN
- 填写指引:物理表与实体的映射规则(一比一/拆分/合并的裁决依据)。

## Identifier

- 起步值:UNKNOWN
- 填写指引:标识符策略:形态、生成方、唯一性范围(逐实体登记)。

## Relation

- 起步值:UNKNOWN
- 填写指引:关系与基数逐对登记(双方、基数、删除语义)。

## lifecycle

- 起步值:UNKNOWN
- 填写指引:对象生命周期:状态集合与允许的转移规则(逐对象登记)。
